Map focus modes: same journey, three treatments

The learned map grows messy over a long run. Pick the default. All stay toggleable in the map toolbar GrowFocusLantern
Mode A Grow
Everything the agent has learned. Complete, but crowds fast: 40+ rooms overlap and labels collide.
Best for: a final overview / export. Worst for: watching a live run.
Mode B Focus radius candidate default
Only ~2 hops around the agent. Distant branches collapse into an expandable “+N” you click to reveal or retract.
Best for: staying oriented on a live run without clutter.
Mode C Lantern
Only the agent and its immediate surroundings are lit: a light held in the dark. Everything beyond the pool stays dark, so focus stays exactly where the action is.
Best for: a live run: zero clutter, all attention on the player. Pan/follow moves the light.
Recommendation: Focus radius as default (cleanest on long runs), Lantern as the “cinematic” toggle for demos and following the agent, Grow for overview/export. Final default decided after we test all three on a real long journey.
